# ADR-001: Linguagem — Go em vez de Node/Python

- **Status:** Aceito
- **Contexto:** O autor já domina Python/Java/Node; o objetivo do projeto é diversificar o portfólio e aprender uma linguagem compilada e concorrente.
- **Decisão:** Usar Go.
- **Consequências:** Curva de aprendizado inicial maior (goroutines, interfaces implícitas); ganho em performance e em demonstrar versatilidade para recrutadores.
