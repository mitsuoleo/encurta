# ADR-006: Autenticação JWT

- **Status:** Aceito
- **Contexto:** O MVP deixou analytics públicos. Precisamos associar links a um dono (RF07) sem sessões no servidor.
- **Decisão:** JWT HS256 (`golang-jwt`), bcrypt (cost 12) para senha, `Authorization: Bearer`. Redirect permanece público. Criação, listagem, analytics e desativação exigem token.
- **Alternativas:** API keys opacas — rejeitado neste ciclo por ser menos familiar em portfólio web; pode coexistir depois.
- **Consequências:** `JWT_SECRET` precisa ser estável entre réplicas. Tokens não são revogáveis até expirarem (24h).
